Seguridad y envíos

MEXOTECH es un proyecto académico. El catálogo presenta productos de ejemplo y aún no permite compras, cobros ni envíos.

Las consultas de soporte se registran en la base de datos para su revisión. No incluyas contraseñas ni datos bancarios en el formulario.

Concepto de pagos en una tienda de tecnología

El pago sería el proceso mediante el cual un cliente cubre el precio de un dispositivo, accesorio o servicio después de conocer el importe total y aceptar las condiciones de compra. En una versión comercial, MEXOTECH mostraría el resumen del pedido, los costos aplicables y el método de pago antes de confirmar la operación. Un proveedor autorizado procesaría los datos de tarjeta u otro medio de pago mediante una conexión HTTPS; la tienda recibiría la confirmación y registraría el estado del pedido, sin almacenar números completos de tarjeta ni códigos de seguridad.

En este proyecto académico no se solicitan datos bancarios ni se realizan cargos. La base de datos sólo contiene productos ilustrativos y consultas de soporte.

Envíos

Una futura tienda requeriría definir precios, existencias, cobertura, condiciones de entrega y un proveedor de pago antes de aceptar pedidos.
